# 色彩検定2級 過去問・練習問題データ

- 参考書問題とは別の `sourceId` とID接頭辞で管理する。
- 過去問は `color2-pe-`、同書の練習問題は `color2-pr-` を使う。
- 年度・期・元の大問番号・枝問・問題ページ・解答ページ・配点を保持する。
- 分割画像は、ユーザーが「これで全部」と明言するまで登録しない。
- 2025年度夏期は17大問・200点を、共通の誤答記録へ保存できる105設問に分解している。
- 2025年度冬期は17大問・200点を、共通の誤答記録へ保存できる104設問に分解している。
- 2025年度版の練習問題は、過去問と混ぜず3大問・18設問で登録する。
- 教材写真や赤ペンの書き込みは転載せず、必要な図版は学習用SVGへ再構成する。
- Vercel連携では、1期分の問題データ・図版・検証をまとめて確認し、最後に1回だけmainへ反映する。
