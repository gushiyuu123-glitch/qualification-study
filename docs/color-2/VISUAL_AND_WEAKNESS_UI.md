# 色彩検定2級｜図版と弱点出題の改善

## 図版

- 実物画像・既存SVGがある問題はそのまま使用する。
- 選択肢に色票がある問題は、選択肢内の色票を視覚情報として扱う。
- 「図」「写真」「ポスター」などを参照するのに図版がない問題は、内容に応じた学習用SVGを自動生成する。
- 既存の静的画像が読み込めない場合も、同じ学習用SVGへ自動的に切り替える。
- 自動生成図には、原本の転載ではないことを明記する。
- 問題画像はタップで拡大できる。

## 弱点ランダム

「間違いだけ」は単純なランダムではなく、次の情報を重みとして出題する。

- 累計誤答回数
- 正解数を上回る未解消誤答
- 要注意フラグ
- 登録した誤答原因

誤答が多い問題ほど出やすくなるが、毎回同じ順番には固定しない。
色彩検定2級のトップ画面から、全教材横断の「苦手から10問」を直接開始できる。

## UI

- 問題進捗を細いバーで表示する。
- 解答後に、選んだ回答と正しい回答を文章で並べる。
- 選択肢別解説がある問題では、4択すべての理由を開いて確認できる。
- 結果画面に不正解数を追加する。
