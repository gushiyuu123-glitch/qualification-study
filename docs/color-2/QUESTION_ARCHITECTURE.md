# 色彩検定2級 問題設計図

この文書は、色彩検定2級の問題を追加・修正するときに、原本の本質を失わないための固定ルールです。
`AGENTS.md` とセットで扱います。

## 1. Source of truth

- 問題文、選択肢、図版、写真、配点、正答は、受領した教科書・問題用紙・解答表を正とする。
- AIの一般知識や推測で、原本の正答を差し替えない。
- 原本内に矛盾・欠落・誤植らしき箇所があっても、勝手に補完して別問題へ変えない。必要なら不整合として明示する。
- 図版や色票は、解答に必要な情報を落とさない。alt、title、descriptionなどから答えを漏らさない。

## 2. 問題の種類を混ぜない

- 教科書に実際に収録された練習問題
- 実際の過去問・試験用紙
- 慣用色名63色の専用ドリル
- 将来ユーザーから明示的に依頼された予測・オリジナル問題

これらは出典表示とIDを分ける。予測問題を過去問・公式問題として扱わない。

## 3. Web版への変換原則

基本方針は **「本質は残す。紙面由来のノイズだけ落とす」**。

残すもの:

- 問われている知識・概念・条件
- 類似概念を区別するための文脈
- 図・写真・色票から読み取る判断材料
- 「最も適切」「誤っている」などの判定条件
- 2026年度型の、一部だけ正しい選択肢や用語混同を狙うフェイント

削ってよいもの:

- 紙面都合で毎問繰り返される共通指示
- 現在の設問と無関係なA〜Jの前後部分
- Web上で現在位置を分かりにくくするレイアウト上のノイズ

ただし、対象空欄を解くために前文・後文が必要なら必ず残す。

## 4. 年度ごとの扱い

### 2025年度

- 比較的素直な知識確認は、その素直さを残す。
- 2026年度風のひっかけを人工的に追加しない。
- 紙面由来の読みにくさだけ改善する。

### 2026年度

- 暗記だけでなく、読解・比較・適用を要求する構造を保つ。
- 正しい数字や説明の近くへ誤った用語を混ぜるタイプのフェイントを簡単化しない。
- 例: RGBの色数計算が正しくても「色料の三原色」とした選択肢は、その誤りを残す。

## 5. 表示層と原本データを分離する

- 読みやすさの改善は、原則として表示アダプター・ガイド側で行う。
- 原本の問題データを、UI都合だけで書き換えない。
- 原本全文へ戻れる導線を残す。
- 記述式を選択式練習へ変換する場合は、その事実を表示する。

## 6. 解説

- 正解だけでなく「どこが判断点だったか」を説明する。
- 2026年度型では、正しい部分と地雷になった部分を分けて説明できるのが理想。
- 解説を足すために、問題そのものを簡単な暗記問題へ変えない。

## 7. 検証

変更後は少なくとも以下を確認する。

- 問題数と配点
- 公式・教科書の正答表との一致
- 選択肢数と順序
- 図版・色票・写真の答え漏れ
- 必要な前後文がWeb表示で欠落していないこと
- 原本データが表示改善によって変更されていないこと
- 2026年度のフェイント構造が残っていること

既存validatorを弱めて変更を通してはいけない。必要な例外は、理由を明示してvalidator側へ追加する。
