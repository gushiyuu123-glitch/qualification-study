# QUALIFY

スマートフォン中心で使う個人用の資格学習アプリです。

## 現在の基盤

- マーケティング検定、Webデザイン技能検定、色彩検定2級を共通構造で管理
- 1〜4のタップ回答、正誤判定、解説表示
- ランダム、誤答、要注意、未回答からの出題
- 回答履歴、正答率、誤答原因、要注意フラグを端末内へ保存
- 教材、カテゴリー、文章問題、コード問題、画像・色見本問題に対応
- 学習データのバックアップと復元
- PWA・オフライン再利用用の基盤

## コンテンツ実装ルール

参考書・公式テキストと、過去問・公式問題集では構造が異なります。
追加・修正前に、ルートの [`AGENTS.md`](./AGENTS.md) を必ず確認してください。

- 参考書系：参考書の章を親章、節・項目を子章としてそのまま実装する
- 過去問系：既存のマーケティング検定3級の問題実装方式を基準にする
- 既存章の削除・移動・置換や、参考書にない余計な階層追加は禁止

## 開発

```bash
npm install
npm run dev
npm run build
```

`main`への反映をVercelの本番デプロイへ接続しています。

教材データと画像を追加する前に、GitHubリポジトリとVercelデプロイのアクセス制限を有効にします。
